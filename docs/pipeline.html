01

What the one command does

The orchestrator stays tiny. It never installs anything itself — it wires up shared helpers, then sources each module in order so they all share the same functions and environment.

02

The shared helpers in common.sh

Modules stay short because the machinery lives here. One of these matters most: as_user is why per-user tools land in your home, owned by you — not root.

idempotent

apt_install

Skips already-installed packages; a missing or renamed one warns and the run continues.

keyring

add_apt_repo

Fetches a key to a signed-by keyring and writes the source list the modern, correct way.

.deb

install_deb

Downloads a vendor .deb to a temp dir and installs it (Obsidian, Bruno, DBeaver…).

drop privileges

as_user

Runs a command as RUN_USER — oh-my-zsh, VSCodium extensions, nvm, uv, bun, Rust, go tools.
